# Demo video script (3 minutes)

The film opens on the commercial, explains the loop with the homepage's own animated flow, then walks the live console screen by screen and closes on the mark.

A voiceover line split on ` ~~ ` is spoken in parts, and `scripts/render_voiceover.py` writes the part offsets to `docs/voiceover/marks.json` so the recorder can light the diagram in time with the words. Kokoro renders the narration (voice `af_heart`, speed per beat). `scripts/make_title.py` draws the title and end cards, `scripts/make_opening.py` builds beat 1 from the ad, `scripts/record_demo.py` records one clip per beat, `scripts/cut_demo.py` cuts each to its narration and lays the track over the whole thing. Output: `docs/video/demo.mp4`.

Nothing in the recording spends: no clearance is started, no square is clicked, no fix is run, no agent question is sent. The finished showcase run (run_959b162a0f25, test_ad.mp4) supplies every result. The launcher and agent mode sit behind the spending door, so those two are filmed against a local instance.

- The showcase run is finished, so tiles do not flip and nothing wears the working ring. The rainbow ring is on the homepage tour door, which carries it by design.
- The intelligence board needs about thirty seconds for its Grafana panels to paint. The recorder waits and the cutter drops that head.
- The cutting room opens on the global master; the France pair is where the drink visibly changes, so the recorder scrolls to it.
