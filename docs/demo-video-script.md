# Demo video script (3 minutes)

The film opens on the commercial itself, then walks the live console screen by screen, and closes on the mark. Voiceover is rendered with Kokoro (voice `af_heart`, speed per beat) into `docs/voiceover/`. `scripts/make_title.py` draws the title and end cards, `scripts/make_opening.py` builds beat 1 from the ad, `scripts/record_demo.py` drives the app and records one clip per beat, `scripts/cut_demo.py` cuts each clip to its narration and lays the track over the whole thing. Output: `docs/video/demo.mp4`.

Nothing in the recording spends: no clearance is started, no square is clicked, no fix is run, no agent question is sent. The finished showcase run (run_959b162a0f25, test_ad.mp4) supplies every result. The launcher and agent mode sit behind the spending door, so those two are filmed against a local instance.

Notes for a re-shoot:

- Only the films this project generated go on camera. The live archive also holds borrowed development footage, so the recorder drops those cards and the weekly panel whose legend names them.
- The showcase run is finished, so tiles do not flip and nothing wears the working ring. The rainbow ring is on the homepage tour door, which carries it by design. Filming a live one costs money.
- The intelligence board needs about thirty seconds for its seventeen Grafana panels to paint. The recorder waits and the cutter drops that head.
- The cutting room opens on the global master; the France pair is the one where the drink visibly changes, so the recorder scrolls to it.
